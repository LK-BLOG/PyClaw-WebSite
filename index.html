PyClaw Lite · Independent Project

想要更轻? 试试 PyClaw Lite

PyClaw Lite 是 PyClaw 的轻量分支,独立仓库、一把 exec 走天下。零插件依赖,纯 Python,给只想快速跑起来的你。

只有一个工具:exec想读文件? cat。想装包? pip。想爬网页? curl。AI 自己动手,什么都能干。
依赖极简只需一个 openai 包,装完即跑;最新版要求 Python 3.10+,早期版本 3.9 也能跑。
CLI + Web 双模式python main.py 进命令行,python webui.py 起网页(默认 8765 端口)。
github.com/LK-BLOG/pyclaw-lite → GPL v3.0 仅一个依赖 
$ git clone https://github.com/LK-BLOG/pyclaw-lite$ cd pyclaw-lite && pip install openai$ cp pyclaw.json.example pyclaw.json$ python main.py# 或者 Web UI:python webui.py → http://localhost:8765
How It Works

各司其职,协作无间

PyClaw 不是单线程的聊天机器人。主 Agent 像项目经理一样拆解任务,把脏活累活分给专职的子 Agent,自己只做判断和决策。

01
统一入口CLI / Web / 桌面三路进,都通向同一个主 Agent。
02
delegate_to 委派主 Agent 按权限把任务派给子 Agent,互不越权。
03
记忆沉淀每一次会话都写入 SQLite,长期记忆随叫随到。

Get Started

一行命令,从零到跑

一条 Bash 命令搞定安装,Windows 的 Git Bash 同样兼容;开发者也可以从源码构建。整个框架安装体积约 10MB,常驻内存约 50MB,轻得不像是带插件系统的。

setuppyclaw setup — 配置向导
startpyclaw start — 桌面 / Web / 后台
chatpyclaw chat "你好" — 一句话问答
shellpyclaw shell — 交互式对话
statuspyclaw status / stop — 状态与停止
$ curl -fsSL https://raw.githubusercontent.com/LK-BLOG/PyClaw/main/install.sh | bash# 或源码安装:$ git clone https://github.com/LK-BLOG/PyClaw.git && cd PyClaw && pip install -e . && pyclaw setup

One Tool, Zero Tools Chain

    
别人给你一整套餐具,我们只给一把刀

    
市面上的 Agent 框架都预置好文件读写、网络搜索、代码执行、数据库工具……看着很全,真遇到活还得自己再造。PyClaw Lite 反过来:只有一个 exec,剩下的让 AI 自己动手。

Self-Evolving

      
能力长在 skills/ 里,
不长在代码里

      
AI 可以把复杂或可复用的逻辑丢进 skills/。下次启动,目录里的每个 SKILL.md 或 .py 都会自动列进系统提示词——AI 立刻知道自己会什么。

      

        
01
代码量不涨,能力在涨新增技能是写一个文件,不是改一处框架。

        
02
SKILL.md 自带 frontmattername / version / description / requires,启动时自动索引。

        
03
插件同源.pyclaw-plugin / .codex-plugin / .claude-plugin 都能识别,贡献工具、钩子、MCP 服务器。

How It Works

      
一个循环,六个子系统

      
主循环只做三件事:把上下文喂给模型、把模型吐出的 exec 调用跑掉、把结果塞回去。其余全是配角,各管一摊。

      

        
01
供应商层目录 / 模型窗口表 / 唯一的流式调用,重试逻辑只有一处。

        
02
权限层命令分段、前缀规则、拒绝名单,危险动作过不去。

        
03
上下文层执行外壳探测(WSL > Git Bash > PowerShell > CMD)、计量、落盘。

Schema-Driven Config

    
一份 pyclaw.json,说清全部行为

    
配置由 schema 驱动:校验、i18n、插件自定义设置都从同一张表长出来。改完存盘即生效,不用重启去猜。

  

  

    

      
字段作用

      
        
PROVIDER / ENDPOINT供应商预设;选 custom 就只用你填的 base URL

        
API_KEY只落在本机 pyclaw.json,不上传任何地方

        
MODEL原样发给接口;模型窗口表按名字自动推断上下文

        
APPROVAL_MODErequest / auto / full —— 危险操作如何批准

        
SHELLauto = WSL > Git Bash > PowerShell > CMD

        
REASONING_EFFORT默认思考强度,单次会话可覆盖

        
CONTEXT_WINDOW0 = 按模型表自动推断

        
COMPACT_*压缩阈值 / 逐字保留比例 / 摘要上限

        
TOOL_OUTPUT_MAX_*输出行数与字节上限,超出部分自动落盘

        
PLUGINS_ENABLED仓库 plugins/ 里的插件在这里逐个开

        
MCP_SERVERSstdio 或 HTTP 的 MCP 服务清单

        
HOOKS事件到命令的映射,12 个事件随你挂

        
ALLOW_RULES命令前缀规则,少弹几次确认

        
BLOCKED_EXTRA追加黑名单,额外直接拒绝的命令片段

        
SUB_AGENTS子 Agent 角色定义,配合 SUB_AGENTS_ENABLED

      
    

  







  

    

      
Get Started

      
四条命令,从零到跑

      
需要 Python 3.10+。install.sh 会装好三个运行时依赖(openai 管接口、prompt_toolkit + rich 管 TUI),顺手建好 history / memory / plugins 目录,可以反复跑。

      

        
install./install.sh — 装 openai + prompt_toolkit + rich

        
configcp pyclaw.json.example pyclaw.json — 填 KEY

        
runpython main.py — 进 TUI

        
plainpython main.py --plain — 极简 CLI,不需要 prompt_toolkit/rich

        
resumepython main.py --continue — 续上次会话

        
testspytest — 85 项测试全部通过

哪边强?各强各的

    
Lite 是内核重写,完整版是生态沉淀。不吹哪边通吃——按你需要什么挑。
